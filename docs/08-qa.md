## Fixed in this checkpoint

From the independent review (docs/08-independent-review.md, 26 findings: 2 high, 8 medium, 16 low), everything the code could fix (D31):

- **High.** The footer keeps its 88 px launcher clearance at every width, so the assistant launcher no longer sits on the motion and cookie switches from 1024 to 1440. The footer's first column has a minimum width and the newsletter stacks its input over its button, so the input is never narrower than 200 px at any width from 768 up.
- **Medium.** The page's H1 is a permanent screen-reader heading and both hero slide headlines are H2s, so an H1 is always exposed after the carousel advances. The motion switch drops the ?motion=off override when switched on. The cookie-choices button appears only when a notice exists, and the notice links the internal privacy page. The assistant panel follows the launcher in the tab order, takes focus on open and returns it on close. The pricing FAQ tells one story on currency. /privacy, /terms, /choose-plan and /digital-business-card redirect to their new pages, and the trust pages link the internal legal copies. The currency switch reaches 44 px.
- **Low.** The hero headline enters with movement only, so it counts as painted (the Lighthouse LCP finding below). The wordmark is no longer preloaded. The chat route answers 200 without a key, so the console stays clean. The share row copies the page the visitor is on and is a labelled group. Article rows say Published and the JSON-LD dates agree. The 404 page has its own title. Copy: 16 countries instead of "worldwide", NFC phones with QR for the rest, digits for counts, glossary spellings (Intelligent Nudges, ICP Matching), no promised reply time, no line repeated between the hero and the next section. On phones the launcher waits for the first scroll so it does not cover the fold's last button.
- **Not the site's to fix.** Public DNS for m.linkist.ai (C21) and the Team plan's yearly unit (C22).

Earlier in the checkpoint:

- Small buttons, nav links, the wordmark link, breadcrumb links, contents links, the footer's cookie and motion buttons, the carousel arrows, the blog filter pills and the assistant's suggestion chips all reach 44 px (D29).
- The security page gained a "This website" section so the reader can tell the site's controls from the app's (brief 7).
- The API check itself: probes are isolated by address so the rate limit only applies where it is tested.
